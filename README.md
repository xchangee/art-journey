# Art Journey | 小阿噗沉浸式画廊

Art Journey 是一个以世界名画为主题的沉浸式网页画廊。项目通过全屏作品展示、动态视频画面、横向缩略图轨道、背景音乐和开场动画，把传统绘画内容转化成更适合网页浏览的艺术体验。

## 项目简介

这个项目的核心目标是让用户像进入一个线上展厅一样浏览名画。页面首屏使用一张带氛围感的封面作为入口，点击“开启探索”后进入主画廊。每一幅作品都会展示标题、艺术家、年份、收藏地点和简短说明，部分作品还配有动态视频版本，用来增强画面的临场感。

项目采用原生 HTML、CSS 和 JavaScript 实现，没有依赖复杂框架，方便直接运行、部署和后续修改。

## 功能亮点

- 沉浸式全屏画廊：作品图片或视频作为主视觉背景，文字信息叠加在画面之上。
- 开场加载页：通过封面图、粒子光效和入口按钮建立展览氛围。
- 作品切换：支持下一幅按钮、缩略图点击、分页圆点和键盘方向键操作。
- 动态素材：部分名画配套 MP4 动态版本，切换时自动判断图片或视频展示。
- 背景音乐：内置三首古典音乐，可在页面右上角播放或暂停。
- 响应式设计：针对桌面端、平板和手机做了布局适配。
- 静态构建：提供 `scripts/build-static.mjs`，可将源码和素材复制到 `dist/` 目录。

## 项目制作过程

1. 确定主题  
   项目选择“世界名画”和“艺术时光旅行”作为核心方向，希望页面不是简单图片列表，而是更接近线上展览或艺术放映厅。

2. 整理素材  
   将图片、视频和音乐分别放入 `artworks/` 与 `audio/` 文件夹。图片用于主视觉和缩略图，视频用于增强部分作品的动态表现，音乐用于营造安静的展览氛围。

3. 搭建页面结构  
   `index.html` 负责页面骨架，包括加载页、主舞台、顶部品牌区、音乐按钮、作品信息区、下一幅按钮和底部缩略图轨道。

4. 编写交互逻辑  
   `script.js` 维护作品数据列表，并完成资源预加载、图片/视频切换、缩略图渲染、分页状态、音乐播放和键盘交互。

5. 设计视觉样式  
   `styles.css` 定义整体视觉系统，包括深色展厅背景、暖金色强调色、古典字体、画面遮罩、按钮动效和响应式布局。

6. 准备发布构建  
   `scripts/build-static.mjs` 会生成可发布的 `dist/` 目录，方便部署到静态网页服务。

## 页面设计过程

页面设计围绕“进入展厅、凝视作品、继续旅行”三个动作展开。

首先，加载页使用整张封面图作为入口背景，按钮放在画面中央偏下的位置，减少多余说明，让用户直接通过视觉感受进入主题。按钮采用暖金色、圆形边框和轻微高光，呼应博物馆、画框和灯光的质感。

进入主页面后，作品本身成为最大视觉主体。图片和视频铺满背景，文字信息只占据画面一侧，避免抢走作品的中心位置。遮罩层用于提升文字可读性，同时保留画面的明暗层次。

底部缩略图轨道承担“浏览目录”的功能。它默认保持克制，用户悬停或操作时再变得更明显，让主画面始终保持沉浸感。分页圆点和当前缩略图状态帮助用户理解自己在整个展览中的位置。

配色上，页面以深黑、暖金和米白为主，模拟夜间展厅与画作灯光；字体选择偏古典的中文衬线字体，让艺术主题更统一。响应式部分则根据屏幕宽度调整文字位置、缩略图尺寸和按钮布局，保证手机端也能完整浏览。

## 本地运行

```bash
npm run dev
```

也可以直接使用任意静态服务器打开项目根目录。

## 构建

```bash
npm run build
```

构建结果会输出到 `dist/`。
